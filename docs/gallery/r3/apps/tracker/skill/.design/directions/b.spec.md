# Direction B: Safety Orange
Thesis: The tracker as shop-floor signage: a saturated safety-orange rail you can see from across the room tells you what's waiting, and heavy condensed numerals make the morning queue feel like a job board to clear.
Axes: density=2 balanced · contrast=3 stark · type=3 expressive display + utility · layout=2 rail + work (bound) · material=3 tonal (machined bezel panel) · motion=3 expressive  (rolls: density=2; contrast/type/material/motion set to 3 by the B rule; layout bound by brief)
Personality recipe: raw-industrial 55% + energetic 25% + dense-expert 20%
Tension resolutions:
  - personality.calm vs energetic → energetic in colour and type only, motion still in budget (daily use)
  - motion.tension-delight-speed → speed on routine paths; expressive curve (snappy, 0.2 bounce) only on triage cleared. Fitted to budget: keyboard 0ms, routine ≤150ms, hero 600ms once a day.
Palette (OKLCH):
  inputs: base hue 60 (concrete) · accent hue 45 (safety orange) · contrast stark
  background oklch(0.92 0.006 60) concrete / foreground oklch(0.16 0.01 60) / muted oklch(0.45 0.01 60) / primary oklch(0.16 0.01 60) ink / mark oklch(0.68 0.2 45) safety orange filling the whole rail / border oklch(0.16 0.01 60 / 0.9) full-weight rules
  dark: background oklch(0.2 0.008 60) / foreground oklch(0.94 0.006 60) / mark oklch(0.7 0.19 45) / border oklch(0.94 0.006 60 / 0.5)
  check: ink on orange ≥ 4.5:1 (L 0.16 on L 0.68)
Type: Big Shoulders Display 800 (counts, view title) + Instrument Sans 400/600 (UI) + JetBrains Mono (keys). why: signage numerals, compact UI body [personality.raw-industrial, typography.limited-families-weights]
Layout concept: orange rail with giant counts per view · list · panel in a machined grey bezel (shell + core)
  composition: rail counts (largest) → list → bezel panel
  focal point: the Triage count in the rail at 64px
Material: tonal bezel — panel is an outer shell oklch(0.86) with inner core paper; radius 0 shell / 0 core; no shadows; 2px ink rules
Craft values: display tracking -0.04em, line-height 0.9; caps labels +0.08em
Icons & imagery: Phosphor bold; no images; initials
Identity motif: hazard-stripe hatching (45° ink stripes) on the P0 marker, the triage header, the empty state
Accent moment: the full-height orange rail
Motion personality: expressive — micro 100 · short 150 · hero 600; snappy (0.23,1,0.32,1); spring bounce 0.2 only on the triage-cleared counter
Signature detail: the rail count flips like a mechanical counter on triage cleared
Fingerprint check: near-black-acid-accent avoided by a light concrete substrate; mono-as-costume avoided (keys only)
