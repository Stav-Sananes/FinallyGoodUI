# Direction A: Monday Paper
Thesis: The Monday read is a one-page briefing: answers set as type in a single column, top to bottom, the way the owner would want a bookkeeper's note to read (brief: "checks it every Monday", finish: editorial).
Axes: density=balanced · contrast=standard · type=humanist/serif text · layout=column · material=flat-hairline · motion=productive  (rolls: grounded)
  grounding: density ← "airy-to-balanced, five answers on one screen"; contrast ← serious + calm; type ← finish "editorial"; layout ← glance read, answer first; material ← editorial (rules, no boxes); motion ← weekly routine + serious.
Personality recipe: editorial 50% + serious-trustworthy 30% + calm 20%
Tension resolutions:
  - data.tension-density-clarity → clarity: owner is not an accountant, weekly glance (brief §Context).
  - craft.tension-restraint-liveliness → A breaks the ink-on-paper house style on one named axis: a coloured primary (deep bottle teal) instead of near-black ink, and a tinted canvas.
  - motion.tension-delight-speed → speed; one runway draw per session.
