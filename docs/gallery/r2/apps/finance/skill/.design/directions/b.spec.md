# Direction B: Monday Statement
Name: the printed bank statement that arrives once a period.
Thesis: The owner reads the week's finances once, top to bottom, like a statement letter: a column of plain sentences with the figures set in them, in strict black and white. Brief: "checks it every Monday".
Axes: density=balanced · contrast=stark · type=neutral grotesk · layout=column · material=flat-hairline · motion=productive  (rolls: density 2 · contrast 3 · type 1 · layout 1 · material 1 · motion 1; no re-rolls; differs from A on 5 axes)
Personality recipe: serious-trustworthy 70% + editorial 30%
Tension resolutions:
  - data.tension-density-clarity → clarity through order: one column, answer first.
  - motion.tension-delight-speed → speed; motion only confirms.
Palette (OKLCH): inputs: base hue 90 (neutral paper) · accent hue 145 (deposit green) · contrast stark
  background oklch(0.99 0.002 90) / foreground oklch(0.16 0.005 90) / muted-foreground oklch(0.44 0.008 90) / primary = ink / mark oklch(0.45 0.1 145) / border oklch(0.86 0.004 90)
  dark: background oklch(0.15 0.004 90) / foreground oklch(0.96 0.003 90) / mark oklch(0.76 0.11 145)
Type: Schibsted Grotesk (headings + text) + IBM Plex Mono for statement line items. why: a newspaper-born grotesk reads as plain reporting; mono only for the statement's aligned line items [typography.limited-families-weights].
Layout concept: 720 px column centred in the content area: a statement header, then "This week" sentence block, then line items (invoices, payroll, spending) as statement rows.
  composition: one reading column top to bottom, answer first; no side-by-side regions.
  focal point: the opening sentence with the cash figure in it.
Material: flat-hairline, rules only, no shadows; radius 0–4.
Craft values: headings -0.015em; caps +0.08em; numbers tabular right-aligned with leader dots.
Icons & imagery: Lucide 1.5; none else.
Identity motif: statement perforation edge — header, between periods, footer.
Accent moment: deposit green on money in.
Motion personality: productive — micro 100 · short 150 · standard 250; the one real transition: Send reminder → row confirms in place.
Signature detail: the perforated tear-line between "this week" and "earlier".
Fingerprint check: mono-as-costume → justified only for aligned line items; default-sans → Schibsted named for its reporting voice. Not built (see D8).
