# Direction A: Ledger Book
Name: the bound ledger a bookkeeper keeps on the desk.
Thesis: A weekly finance check should feel like opening a well-kept book: the totals that matter sit in a fixed rail you learn once, and the week's work (who to chase) fills the page beside it. Brief: "checks it every Monday".
Axes: density=balanced · contrast=standard · type=humanist/serif text · layout=rail + work · material=soft-elevated · motion=balanced  (rolls: grounded)
  grounded because: balanced density for a weekly glance with a list to act on (data.tension-density-clarity); standard contrast and a transitional serif for headings from personality.serious-trustworthy; rail + work because the summary (cash, runway, payroll) is read and the invoice list is acted on (data.dashboard-summary-first); soft-elevated for a laptop work tool; balanced motion for weekly, non-expert use (system.md motion table).
Personality recipe: serious-trustworthy 60% + calm 40%
Tension resolutions:
  - data.tension-density-clarity → balanced: weekly use, but the invoice list is acted on.
  - motion.tension-delight-speed → speed; signature on Mark paid.

  composition: rail of totals → wide invoice table → spending; A differs from B (single column) and C (stage).
